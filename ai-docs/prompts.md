# Prompts

Prompts that worked well. Add new ones with a short note on when to use them.

## Session start
> Read CLAUDE.md and ai-docs/next_steps.md. Show me the plan for the next task and wait for my permission.

## Start a stage
> Use the phase-runner skill for Stage <N>. Plan first, then small steps. Notify me at each step.

## New table / DB feature
> Use the sqlite-feature skill to add the `<table>` table: <columns>. Show the plan first.

## New screen
> Use the ui-ux skill to build the <Screen> page. Show the component tree first.

## AI feature review
> Run the responsible-ai-check skill on <feature/file>.

## Explain code
> Explain this file line by line in Uzbek, simply.

## Debug
> This error appeared: <error>. Find the cause first, explain it, then propose the fix. Don't change other code.
